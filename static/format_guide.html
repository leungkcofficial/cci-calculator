File Format Guide

Learn how to properly format your input files for the CCI Calculator

← Back to Calculator
Introduction

The CCI Calculator accepts patient data in three formats: CSV, Excel, and JSON. This guide explains the required fields and format for each file type.

All formats require the following information:

  • Patient ID - A unique identifier for each patient
  • Age Information - Either the patient's age OR both date of birth and entry date
  • ICD-10 Codes - One or more valid ICD-10 diagnosis codes (maximum 30 codes per patient)
Required Fields
Field Type Required Description
patient_id String Yes Unique identifier for the patient
age Integer Conditional* Patient's age (0-120)
dob Date (YYYY-MM-DD) Conditional* Patient's date of birth
entry_date Date (YYYY-MM-DD) Conditional* Date of record entry/assessment
icd_codes Array/List of Strings Yes List of ICD-10 diagnosis codes (max 30)

* Either age OR both dob and entry_date must be provided.

ICD-10 Code Format

ICD-10 codes must follow the standard format:

  • Start with a letter (A-Z)
  • Followed by one or more digits
  • Optionally include a decimal point and additional digits
  • Example: I21.0, E11.9, C50.9
CSV Format

CSV files should include a header row with the field names, followed by data rows for each patient.

Example CSV Structure:
patient_id,age,icd_codes P001,45,"I21.0,I50.9,E11.9" P002,67,"C50.9,C79.3,I10" P003,82,"F03,J44.9"
Alternative with DOB instead of Age:
patient_id,dob,entry_date,icd_codes P001,1980-05-15,2025-04-30,"I21.0,I50.9,E11.9" P002,1958-03-22,2025-04-30,"C50.9,C79.3,I10" P003,1943-11-10,2025-04-30,"F03,J44.9"

Notes:

  • The icd_codes column should contain comma-separated ICD-10 codes
  • Enclose the ICD codes in quotes to ensure they're parsed as a single field
  • Date fields should use the YYYY-MM-DD format

Excel Format

Excel files (.xlsx, .xls) should have the same structure as CSV files, with column headers in the first row.

Excel Structure:
patient_id age icd_codes
P001 45 I21.0,I50.9,E11.9
P002 67 C50.9,C79.3,I10
P003 82 F03,J44.9

Notes:

  • ICD codes can be entered as comma-separated values in a single cell
  • Alternatively, you can use separate columns for each ICD code (e.g., icd_code_1, icd_code_2, etc.)
  • The system will read from the first sheet in the workbook

JSON Format

JSON files can use two different structures:

Option 1: Array of Patient Records
[ { "patient_id": "P001", "age": 45, "icd_codes": ["I21.0", "I50.9", "E11.9"] }, { "patient_id": "P002", "age": 67, "icd_codes": ["C50.9", "C79.3", "I10"] }, { "patient_id": "P003", "dob": "1943-11-10", "entry_date": "2025-04-30", "icd_codes": ["F03", "J44.9"] } ]
Option 2: Object with Patients Array
{ "patients": [ { "patient_id": "P001", "age": 45, "icd_codes": ["I21.0", "I50.9", "E11.9"] }, { "patient_id": "P002", "age": 67, "icd_codes": ["C50.9", "C79.3", "I10"] }, { "patient_id": "P003", "dob": "1943-11-10", "entry_date": "2025-04-30", "icd_codes": ["F03", "J44.9"] } ] }

Notes:

  • The icd_codes field should be an array of strings
  • Date fields should use the YYYY-MM-DD format as strings
  • The age field should be a number

Common Errors
Error Description Solution
Missing required fields Patient ID or ICD codes are missing Ensure each record has at least patient_id and icd_codes
Missing age information Neither age nor dob+entry_date provided Include either age OR both dob and entry_date
Invalid ICD-10 code format ICD codes don't match the required pattern Ensure codes start with a letter followed by numbers (e.g., I21.0)
Invalid date format Dates not in YYYY-MM-DD format Use ISO date format (YYYY-MM-DD)
Age out of range Age value less than 0 or greater than 120 Ensure age is between 0 and 120
